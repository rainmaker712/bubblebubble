# BubbleBubble

낙콩과 무닝이 거품으로 공룡 귀신을 잡는 개인용 로컬 웹 게임 프로토타입입니다.

## 바로 실행하기

최초 한 번 의존성을 설치합니다.

```bash
cd /Users/user/github/bubblebubble
npm install
```

이후에는 Python 실행기를 사용할 수 있습니다.

```bash
cd /Users/user/github/bubblebubble
python3 run_game.py
```

브라우저가 자동으로 열리지 않으면 [http://127.0.0.1:4173](http://127.0.0.1:4173)에 접속합니다. 서버를 종료할 때는 터미널에서 `Ctrl+C`를 누릅니다.

또는 `npm run dev`로 Vite 개발 서버를 직접 실행할 수 있습니다. 이 게임은 Phaser 4.2.1, TypeScript, Vite로 구성되어 있어 `index.html`을 파일로 직접 열 수 없습니다.

## 조작법

| 캐릭터 | 이동 | 점프 | 거품 |
|---|---|---|---|
| 낙콩(1P) | `A` / `D` | `W` | `F` |
| 무닝(2P) | `←` / `→` | `↑` | `.` |

- 첫 스테이지는 왕의 체력을 모두 깎아 클리어합니다. 이후 스테이지에서는 공룡 귀신에게 거품을 맞혀 가둔 다음, 갇힌 거품에 캐릭터 몸으로 닿으면 제거됩니다.
- 발사 직후 전진하는 거품을 적에게 직접 맞혀야 포획할 수 있습니다.
- 빈 거품은 점프 키를 누른 상태로 위에서 밟으면 튀어 오릅니다.
- 발판은 아래에서 점프로 통과할 수 있고 위에서 내려올 때 착지합니다.
- 바닥 구멍으로 떨어지면 화면 위에서 다시 나타나며, 포획 거품도 천장과 바닥을 순환합니다.
- 공룡 귀신이 떨어뜨리는 `E`, `X`, `I`, `T`를 모두 모으면 5,000점 보너스와 함께 다음 스테이지로 이동합니다.
- 생명이 모두 소진되면 10초 안에 `C`를 눌러 현재 스테이지를 이어서 할 수 있습니다.
- `Esc`로 일시정지합니다.
- 화면 아래 `음악 켜짐/꺼짐` 버튼으로 오리지널 BGM `달빛 방울 행진곡`을 전환할 수 있습니다.

## 현재 범위

- 난이도와 테마가 달라지는 스테이지 10개: 달빛, 별빛, 유령 탑, 사탕 동굴, 무지개 하늘섬, 심해 신전, 장난감 공장, 얼음 궁전, 화산 심장, 우주 성채
- 1인 또는 같은 키보드의 2인 로컬 플레이
- Phaser 4 Arcade Physics, Scene, 카메라, 파티클, 트윈 애니메이션 사용
- TypeScript strict mode와 Vite 빌드
- Python은 개발 서버 실행 보조와 향후 백엔드 확장용
- 공룡 귀신 처치 시 딸기·바나나·쿠키가 등장하며, 먹으면 점수 획득
- 스테이지별 적 수 4~12마리, 버블룬·보블룬 실루엣과 10가지 테마 장식, 서로 다른 발판 색
- 첫 보스전은 100초, 이후 스테이지는 난이도에 따른 제한 시간 적용
- 빠른 연사의 물방울, 고속 거품의 불꽃, 이동·점프를 높이는 신발, 공격 한 번을 막는 방패, 점프 키로 날 수 있는 구름 아이템
- 과일과 간식은 캐릭터 크기를 바꾸지 않고 점수만 제공
- 주요 캐릭터와 아이템을 2배 내부 해상도로 그리는 고해상도 Canvas 텍스처 사용
- 고해상도 텍스처와 별도로 물리 판정 크기를 보정하고, 아이템에는 근거리 보조 획득 판정 적용
- 피격 또는 CONTINUE 이후 3초 동안 무적
- 일반 스테이지에서 시간이 0이 되면 실패 대신 해골 모습의 무적 귀신 고래가 출현하며, 화면 효과와 음악이 위험 모드로 전환
- EXIT 알파벳은 적 처치당 22% 확률로만 드롭
- 개인 컴퓨터에서만 사용하는 비공개 프로토타입

설계 결정은 [docs/ADR.md](docs/ADR.md), 스테이지 원본 데이터는 [docs/samples/stage-01.json](docs/samples/stage-01.json)에서 확인할 수 있습니다.

## 10월 18일 추가 업데이트

- 손그림을 바탕으로 낙콩(긴 귀, 날개, 하트 장식과 꽃 지팡이)과 무닝(고양이 귀, 윙크, 볼과 꽃 장식)을 Canvas로 구현했습니다. 원본이 흑백이므로 크림색·연보라색과 파스텔 장식을 적용했습니다.
- 무지개 아이템은 시간제한 없이 귀신·귀신 고래와의 충돌 10회를 막습니다. 겹쳐 있는 동안은 1회로 세고, 떨어졌다 다시 닿으면 추가 차감합니다. 10번째 접촉도 보호하며, 종료 직후 0.8초의 여유 시간을 줍니다. 잔여 횟수는 캐릭터 위에 표시되며 다음 스테이지에도 유지됩니다. 보호를 모두 사용해도 무지개 거품 색상은 목숨을 잃기 전까지 유지됩니다.
- 특수 능력 아이템은 스테이지당 최대 2개입니다. 점수용 간식과 EXIT 글자 드롭은 별도입니다.
- 귀신 AI는 거리 기반 목표 선택, 이동 방향 예측, 거품 회피 점프, 발판 끝 판단과 무지개 플레이어 회피를 사용합니다. 판단 주기와 점프 대기시간을 두어 프레임 속도에 따른 무작위 점프를 제거했습니다.
- 2P 거품 키는 `.`입니다. 1P는 `F`입니다.
- 프레임워크 변경 없이 기존 Phaser 구조를 유지했습니다.

검증: `npm test` (Node 22.6 이상), `npm run build`.

## 첫 스테이지 보스전 · 아케이드 그래픽

- 첫 스테이지는 **번개 왕의 성**입니다. 왕의 체력은 1인 24, 2인 36이며, 왕을 처치해야 5,000점을 받고 2스테이지로 이동합니다. EXIT 글자로 보스전을 건너뛸 수 없습니다.
- 일반 거품은 피해 1, 번개는 빠르고 긴 사거리로 피해 2, 불꽃은 피해 3입니다. 왼쪽의 번개와 오른쪽의 불꽃, 총 두 아이템을 배치했습니다. 획득한 속성은 다음 스테이지에도 유지되고 목숨을 잃으면 초기화됩니다.
- `F`(1P) / `.`(2P)를 누르고 있으면 연사합니다. 점프와 발판을 활용해 왕을 맞히세요.
- 왕은 1초 동안 표시되는 낙뢰 경고와 0.7초 동안 표시되는 불꽃 경고 뒤에 공격합니다. 낙뢰는 표시된 세로 영역을, 불꽃은 세 방향으로 날아오는 탄을 피해야 합니다. 체력이 절반 이하가 되면 낙뢰가 두 줄이 되고 공격이 빨라집니다.
- 첫 스테이지의 100초 제한이 끝나면 왕의 공격 주기가 더 빨라집니다. 보스전에는 귀신 고래가 추가로 나타나지 않습니다. CONTINUE 시 왕의 체력은 유지하고 위험 탄을 제거하며 준비 시간을 줍니다.
- 낙콩·무닝의 원본 스케치 기반 그래픽은 유지했습니다. 나머지 배경·벽돌·적·왕·거품·아이템·간식·EXIT·귀신 고래·파티클은 코드로 새로 그린 도트 그래픽입니다.
- 참고: [게임톡, 게임별곡 보글보글 (2013)](https://www.gametoc.co.kr/news/articleView.html?idxno=8378). 기사 속 검은 플레이필드, 색색의 벽돌과 100라운드 대형 보스 구성을 참고했습니다. 기사 이미지는 게임 리소스에 포함하지 않았습니다.

추가 그래픽 기준은 `imgs/basic-char.png`입니다. 8종의 일반 적(투구·흰 유령·보라 돔·뿔 몬스터·얼음 유령·빨간 러너·청록 몬스터·초록 마법사), 포획 전용 모습과 초록색 대형 왕을 반영했습니다. 물약·분홍 신발·물/번개/불 거품을 다시 그렸고, 사과·포도·체리 점수 아이템도 추가했습니다.

보스 통합 검증은 Vite(`npm run dev -- --port 4175`)와 Chrome 원격 디버깅 포트 9337을 켠 뒤 `node scripts/check_boss_browser.mjs`로 실행합니다. 보스 클리어 조건, 속성 피해, 경고와 실제 공격, 일시정지, 분노 단계, CONTINUE, 다음 스테이지 정리, 포획 그래픽 및 2P `.` 입력을 확인합니다.
