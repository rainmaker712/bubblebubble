# Unity 전환 · 2026-10-22

저장소 루트를 Unity 6000.3.26f1 프로젝트로 구성했다. 원래 Phaser 소스는 삭제하지 않았으며, Unity 플레이어는 JavaScript·브라우저·개발 서버 없이 실행된다.

## 구조와 의도한 차이

`GameWorld`는 Unity API에 의존하지 않는 C# 게임 상태다. 논리 좌표는 원작과 같은 512×448, 아래쪽이 +Y다. `GameApp`이 Unity의 위쪽 +Y 좌표로 바꾸어 `SpriteRenderer`에 표시한다. 프레임 누적기로 60Hz 업데이트를 수행하고, 입력의 점프 누름은 다음 시뮬레이션 프레임까지 보관한다. 거품과 공격의 시간도 이 시뮬레이션 시간을 사용하므로 일시정지 중 효과가 진행되지 않는다.

Phaser 물리를 그대로 재현하는 대신 축 정렬 충돌과 하강 시 착지 판정을 C#으로 구현했다. Unity `Rigidbody2D`나 WebView를 사용하지 않는다. 따라서 적의 이동 경로·점프 감각·파티클 궤적이 웹 버전과 프레임 단위로 같지는 않다. 렌더링은 Unity 기본 렌더 파이프라인이며 UI는 IMGUI, 오디오는 AudioSource다. 에디터에서 직접 편집하는 UI 프리팹이나 Animator 컨트롤러는 사용하지 않는다.

스테이지는 `Resources/Stages`를 유일한 Unity 데이터 원본으로 쓴다. 그림은 기존 Canvas 드로잉을 PNG로 한 번 변환했으며 런타임에 TypeScript를 실행하지 않는다. 한글 폰트와 라이선스를 포함하여 다른 컴퓨터에서도 시스템 폰트 설치에 의존하지 않는다.

별똥별은 발사 순간 대상을 예약해 2인 동시 발사·연속 발사 시 같은 적을 두 번 처치하지 않는다. 처치 보상은 즉시 만들고 별이 적 위치로 이동한 뒤 데려간다. 새 스테이지에서 이전 이펙트 목록을 지운다. 보호 횟수가 0이 되어도 무지개 색상 능력은 해당 스테이지에서 목숨을 잃기 전까지 남는다.

## 로컬 설치와 검증

- Apple Silicon용 Unity Hub와 Unity Editor 6000.3.26f1 설치.
- Editor 경로: `/Applications/Unity/Hub/Editor/6000.3.26f1/Unity.app`.
- Main 씬·Force Text 직렬화·2D 에디터 모드·창 모드 1024×896·기본 키보드 입력 설정.
- Edit Mode 규칙 테스트 17개, Play Mode 통합 테스트 1개.
- macOS 독립 실행 앱 빌드와 실행 확인.
- Windows/Web 빌드 함수는 제공하지만 해당 모듈 설치와 플랫폼 실행 검증은 하지 않았다.

Unity 버전과 다운로드는 [공식 릴리스](https://unity.com/releases/editor/whats-new/6000.3.26f1), Hub 설치 명령은 [공식 CLI 문서](https://docs.unity.com/en-us/hub/use-hub-cli)를 기준으로 확인했다. 이 Mac에서는 공식 서명된 ARM64 패키지를 내려받아 앱을 배치했다. 다른 컴퓨터에서는 Hub 설치를 권장한다.

## 재현 명령

```sh
python3 scripts/unity.py doctor
python3 scripts/unity.py setup
python3 scripts/unity.py test
python3 scripts/unity.py build --target mac
python3 run_game.py
```

Unity는 같은 프로젝트를 동시에 두 Editor 프로세스에서 열 수 없다. 테스트·빌드 명령 전에 해당 프로젝트의 Editor를 닫는다. 실행 중인 독립 게임 앱은 별도 프로세스다. 보고서·로그·빌드는 `TestResults/`, `Builds/`에 생성되며 Git에서 제외한다. `Assets` 내부 `.meta` 파일과 `Packages/packages-lock.json`은 함께 버전 관리한다.

2026-10-22 리뷰 4~8번 추가 반영으로 첫 보스전은 마지막 10탄으로 이동했다. 스테이지 효과 승계 규칙은 폐기했으며, 자세한 현재 동작은 [추가 구현 기록](updates/review-10-22-implementation.md)을 참조한다.
