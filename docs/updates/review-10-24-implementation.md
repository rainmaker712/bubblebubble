# 10/24 업데이트

- 인원 선택 → 한국어 음성 프롤로그 8장 → 도쿄빙수 1탄 순서로 진행합니다. 자막과 음성은 같은 이야기이며 이전·다음·다시 듣기를 지원합니다.
- 한국어 Yuna 음성을 WAV로 게임에 포함했습니다. 실행 중 TTS 서비스나 인터넷은 필요 없습니다. 재생성: `python3 scripts/generate_story_voice.py` (macOS).
- 1~6탄: 도쿄빙수 가게, 딸기 케이크 공방, 아이스크림 나라, 마카롱 정원, 물고기 수족관, 시원한 수박 코너. 각 테마의 배경색·장식·발판·간식 보상을 적용했습니다. 기존 발판 위치와 7~10탄은 유지했습니다.
- 똥 아이템은 일반·보스 스테이지의 랜덤 아이템에 포함되며 기존 스테이지당 2개 제한을 지킵니다. 획득 시 점수 보상이나 시간 차감은 없습니다.
- 똥 획득 후 시간 초과나 쓰레기통으로 고래귀신이 등장하면 물고기 부하 3마리가 함께 나타납니다. 이미 고래가 있으면 즉시 추가됩니다. 물고기는 추적하며 거품 포획·처치가 가능합니다.
- 물고기는 스테이지당 한 무리만 생성합니다. 효과는 생명 손실·이어하기에도 유지되며 스테이지 변경·새 게임에서 초기화됩니다.
- 게임 규칙 테스트에 테마 보상, 아이템 랜덤 풀, 고래 등장 전후 획득, 중복 방지, 포획, 초기화 사례를 추가했습니다. Play Mode에서는 1인·2인 모두 프롤로그와 실제 음성 재생을 거쳐 게임에 진입하는지 검사합니다.

## 프롤로그 확장

함께 간식을 나누던 일상 → 텅 빈 냉장고 → 쿠키 뒤의 거품 단서 → 귀신을 따라 냉장고 너머로 이동 → 여섯 테마 지도 → 거품 능력 발견 → 마지막 쿠키를 나누는 약속 → 도쿄빙수 도착으로 8장을 구성했습니다. 각 장은 세 줄의 자막과 한국어 음성을 제공합니다. 이전·다음·다시 듣기는 그대로 사용할 수 있습니다.

자막과 음성 대본의 공통 원본은 `Assets/BubbleBubble/Resources/Story/prologue.json`입니다. 문구 수정 후 `python3 scripts/generate_story_voice.py`로 음성을 다시 생성합니다.

## 엔딩

최종 보스 클리어 → 간식 회수 → 거품 길을 따라 귀가 → 냉장고 채우기 → 함께 빙수를 나눠 먹기로 4장의 엔딩과 한국어 음성을 추가했습니다. `Resources/Story/ending.json`이 자막·음성의 공통 원본입니다. 마지막 장을 넘기면 점수를 유지한 클리어 화면이 나오며 엔딩이 반복해서 열리지 않습니다. 다시 시작하면 프롤로그부터 진행합니다.

스토리 확장 검증: Edit Mode 21개, Play Mode 3개 통과. 1인·2인 프롤로그 8장 음성, 엔딩 4장 음성, 마지막 보스 승리 시 자동 진입, 이전 장 이동, 최종 점수 유지, 엔딩 재진입 방지, 새 게임 복귀를 확인했습니다.
