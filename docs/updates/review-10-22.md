# 추가 업데이트 사항

1. 아이템은 목숨이 없어질때 까지 유지된다
2. 무지개 아이템을 먹으면 버블을 쏠 때 버블이 알록달록 무지개 색이 되게 제작해주세요.
3. 별동별 아이템
  - 버블을 쏘면, 별동별이 나타나 귀신이나 몬스터 1개를 없애는거 (데려가는것)
  - 대신, 별동별 아이템은 1개 스테이지에 최대 2번만 나올수 있습니다.


4. 아이템이 스테이지 1개가 지나가면 효과는 없어지는거야
5. 아이템이 랜덤으로 게임 중에 나오게 하면 좋겠어
6. 시간이 다되면 나오는 유령고래가 진짜 버블버블에 나오는 유령고래로 변경됬으면 좋겠어
7. 안 좋은 아이템을 하나 추가하고 싶어. 쓰레기통 아이템인데, 쓰레기통 아이템을 먹으면 유령고래가 튀어나와
8. 1탄에서나오는 보스를 맨 마지막 스테이지로 미뤄줘. 보스 스테이지 나오는 보스는 랜덤하게 종류가 바뀌었으면 해
