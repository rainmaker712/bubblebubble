# 10월 22일 리뷰 4~8번 구현

현재 실행 버전인 Unity 프로젝트에 반영했다. 4번이 이전의 스테이지 간 유지 규칙을 대체한다. 기존 Phaser 게임 로직은 이번 변경 대상이 아니며, `src/game/arcadeArt.ts`는 Unity PNG를 생성하는 공용 그림 소스로 갱신했다.

## 4. 아이템 효과 종료

- 물·불·번개·신발·방패·구름·무지개·별똥별 효과는 획득한 스테이지에서만 유지된다.
- 같은 스테이지에서도 목숨을 잃으면 능력이 해제된다. 방패 1회와 무지개 보호 10회 소모 규칙은 유지한다.
- 다음 스테이지 진입 시 두 플레이어 모두 새 능력 상태로 시작하며 목숨과 점수는 이어진다.
- 이전 스테이지의 거품·별똥별·아이템·유령고래도 정리한다.

## 5. 플레이 중 랜덤 등장

고정 아이템 배치를 제거했다. 첫 아이템은 시작 후 4~8초 사이, 다음 아이템은 첫 등장으로부터 8~12초 뒤에 등장한다. 타이머는 일시정지·스테이지 전환·이어하기 대기 동안 멈춘다.

종류와 위치를 무작위로 선택한다. 발판 바로 위의 빈 공간에 배치하며 플레이어·다른 아이템·적·보스와 너무 가까운 위치는 제외한다. 적절한 위치가 없으면 0.5초 뒤에 다시 시도한다. 일반 스테이지에서는 기존 8종 능력과 쓰레기통이 후보이며, 일반 적이 없는 보스전에서는 별똥별과 신발을 제외한 7종이 후보가 된다.

스테이지당 전체 특수 아이템 최대 2개 규칙을 유지하므로 별똥별도 최대 2개다. 획득·사망·이어하기로 등장 횟수가 초기화되지 않는다. 다음 스테이지에서 새 등장 계획을 만든다. 간식과 EXIT는 이 제한과 별개다.

## 6. 원작형 유령고래

기존의 길쭉한 파란 고래를 흰 해골 몸, 붉은 눈, 검은 톱니 입을 가진 Skel-Monsta 형태로 다시 그렸다. 입 모양 2프레임을 번갈아 표시한다. 벽을 통과하여 플레이어를 추적하며 거품·별똥별로 제거되지 않는 기존 규칙은 유지한다.

캐릭터명과 형태 참고: [Skel-Monsta 설명](https://bubblebobble.fandom.com/wiki/Skel-Monsta), [픽셀 그림 참고](https://www.clipartmax.com/middle/m2i8b1N4m2m2m2G6_beautiful-online-background-colour-change-of-photo-bubble-bobble-pixel/). 참고 이미지를 게임 파일로 넣는 대신 기존 코드 기반 픽셀 그림 생성 방식으로 재작성했다.

## 7. 쓰레기통

- 회색 쓰레기통 그림, 붉은 강조와 `쓰레기통 · 위험!` 표시를 추가했다.
- 획득하면 시간이 남아 있어도 유령고래를 즉시 소환한다. 점수 보상은 없다.
- 보스전에서도 작동하고 위험 음악으로 전환된다. 남은 시간을 강제로 0으로 바꾸지는 않는다.
- 소환 순간 접촉 피해를 피할 수 있도록 살아 있는 플레이어들에게서 가장 먼 모서리에 나타난다.
- 이미 고래가 있으면 추가로 복제하거나 위치를 초기화하지 않는다. 이어하기에는 남고, 다음 스테이지에서 사라진다.

## 8. 최종 랜덤 보스

1탄은 일반 적 4마리와 점프로 이동할 수 있는 발판으로 구성했다. 2~9탄은 기존 일반 스테이지이며, 10탄을 보스 전용 경기장으로 변경했다.

| 보스 | 모습 | 공격 |
| --- | --- | --- |
| 번개 왕 | 기존 초록 왕 | 낙뢰와 3방향 불꽃을 번갈아 사용, 분노 시 낙뢰 2줄 |
| 불꽃 왕 | 붉은 몸과 불꽃 장식 | 빠른 3방향 불꽃, 분노 시 5방향 |
| 얼음 왕 | 푸른 몸과 얼음 왕관 | 위에서 떨어지는 얼음 3개, 분노 시 5개 |

최종 스테이지 입장마다 3종 중 하나를 무작위로 선택한다. 같은 보스가 연속해서 나올 수도 있다. 이어하기 시 종류와 남은 HP는 유지하고 위험 공격을 제거한다. 모든 보스의 HP는 1인 24 / 2인 36이고, 기본·물 피해 1 / 번개 피해 2 / 불 피해 3이다. 보스를 쓰러뜨리면 전체 게임 클리어가 된다.

## 검증

- 변경 전에 신규 규칙 테스트를 실행하여 기존 동작에서 실패하는 것을 확인했다.
- Unity Edit Mode 규칙 테스트 17개: 능력 초기화, 랜덤 종류·위치, 일시정지, 등장 예산, 쓰레기통·시간 초과 고래, 보스 배치·종류·공격·경고·이어하기 등.
- Play Mode 통합 테스트 1개: 10개 스테이지, 추가 그림·한글 폰트·셰이더, 3종 보스 렌더링·위험 공격, 쓰레기통 획득·고래 소환.
- 테스트 렌더 이미지: `TestResults/unity-first-stage-world.png`, `unity-skel-monsta.png`, `unity-boss-lightning.png`, `unity-boss-fire.png`, `unity-boss-ice.png`. 카메라 렌더링 결과이므로 HUD는 포함하지 않는다.
- macOS 앱: `Builds/macOS/BubbleBubble.app`. 실행: `python3 run_game.py`.
