# 첫 실행 후 업데이트 사항 정리

1. 괴물 케릭터가 그 자리에서만 왔다갔다 하고, 아래롤 내려오지 않아
2. 괴물이 버블을 맞았을 때, 버블 안에 괴물이 보이지가 않아
3. 버블을 터트렸을 때 점수가 올라가는 과일이나 간식이 나오지 않아
4. 스테이지 블록이 조금 개선 됬으면 좋겠어. 다음 스테이지로 가면 더 어려운 블록이 됬으면 해
5. 간식이랑 과일을 먹으면, 몸이 조금씩 커지면 좋겠어

## 반영 결과

- [x] 추적 AI가 플레이어가 아래에 있을 때 발판 끝에서 내려오도록 변경하고, 위에 있을 때는 점프를 시도하도록 개선
- [x] 포획된 버블룬·보블룬을 거품 안에 축소·반투명 상태로 표시
- [x] 공룡 귀신 제거 시 딸기(250점), 바나나(350점), 쿠키(500점) 드롭
- [x] `달빛 놀이터` → `별빛 계단` → `유령 탑`의 3스테이지로 확장하고 블록과 적 수를 단계적으로 증가
- [x] 과일·간식 획득 시 캐릭터가 8%씩, 최대 138%까지 성장하도록 적용

마지막 공룡 귀신이 떨어뜨린 간식까지 획득하면 다음 스테이지로 넘어간다. 성장 크기와 남은 생명은 다음 스테이지에 이어진다.

# 추가 업데이트 사항 2

6. 적이 죽은 다음 버블을 터트리면 과일이나 간식이 바닥에 떨어지는게 잘 보이지 않아
7. 스테이지가 변경되면 추가 아이템이 반영됬으면 좋겠어 (불, 물 등등)
8. 그리고 스페셜 아이템으로 알파벳이 나왔으면 좋겠어 (EXIT) 알파벳을 다 모으면 보너스와 다음 스테이지로 가는거야
9. 적의 모습이 다양했으면 좋겠어 (스테이지 넘길때마다)
10. 점프를 하면 올라가는 블록이 패스가 되야하는데 안되는거 같아
11. 적한테 버블을 직접쏴야 잡힐수 있게 바꿔줘
12. 적의 개수가 조금 더 많았으면 좋겠어
13. 스테이지 당 초를 200초 기준으로 바꿔 줬으면 해

## 추가 업데이트 반영 결과

- [x] 과일·간식에 밝은 원형 표식과 `▼ 간식` 라벨을 붙이고, 화면 밖이나 바닥 아래로 떨어지지 않도록 생성 위치를 보정
- [x] 2스테이지에 `물방울` 아이템(12초 빠른 연사), 3스테이지에 `불꽃` 아이템(12초 고속 거품) 추가
- [x] 적을 제거할 때 `E → X → I → T`가 차례로 등장하며, 모두 모으면 5,000점 보너스와 함께 즉시 다음 스테이지로 진행
- [x] 스테이지별로 공룡 귀신의 색과 장식이 달라지도록 3종 외형 테마 적용
- [x] 플레이어가 아래에서 점프할 때 발판을 통과하고, 내려올 때만 발판 위에 착지하는 단방향 발판 적용
- [x] 발사 직후 전진 중인 거품이 적에게 직접 닿았을 때만 포획하도록 판정 변경
- [x] 적 수를 스테이지 순서대로 4마리, 6마리, 8마리로 증가
- [x] 모든 스테이지 제한 시간을 200초로 통일

EXIT 수집 현황은 상단 HUD의 `EXIT [E _ I _]` 형식으로 표시된다. 일반 클리어는 모든 적을 제거하고 떨어진 간식을 전부 먹었을 때 진행되며, EXIT 네 글자를 먼저 모으면 남은 적과 관계없이 보너스 클리어가 적용된다.


# 추가 업데이트 사항 3

14. 버블이 찬 적들이 천장으로 가면 그게 이어서 아래에서 다시 나올수 있게 변경해줘. 바닥에 구멍 자체가 돌 수 있께 해줘
15. 시간은 300초로 해주고
16. 추가로 특정 버튼을 누르면 케릭터 생명이 다 소모되도 이어서 할 수 있게 해줘

## 추가 업데이트 사항 3 반영 결과

- [x] 적이 들어 있는 포획 거품이 천장 위로 올라가면 바닥 쪽에서 다시 나타나 계속 상승하도록 세로 순환 적용
- [x] 각 스테이지 바닥에 순환 구멍을 추가하고, 플레이어·적·과일·간식·EXIT 글자가 아래로 빠지면 화면 위에서 다시 등장하도록 변경
- [x] 모든 스테이지 제한 시간을 300초로 통일
- [x] 모든 플레이어의 생명이 소진되면 10초 동안 CONTINUE 안내를 표시하고, `C` 키를 누르면 현재 적·점수·아이템 진행 상태를 유지한 채 생명 3개로 재개

CONTINUE 대기 중에는 게임과 제한 시간이 잠시 멈춘다. 10초 동안 `C` 키를 누르지 않으면 결과 화면으로 이동한다.


## 추가 업데이트 사항 4

17. 스테이지 별 블록의 색이 변했으면 좋겠어

## 추가 업데이트 사항 4 반영 결과

- [x] 스테이지 팔레트에 맞춰 발판 색이 보라 → 파랑 → 자주 → 사탕 분홍 → 민트색으로 달라지도록 적용
- [x] 기존 3개 스테이지 뒤에 `사탕 동굴`, `무지개 하늘섬`을 추가해 총 5개 스테이지로 확장
- [x] 달빛·별빛·유령 탑·사탕 동굴·하늘섬마다 배경 장식과 기류, 발판 배치, 적 외형과 수를 다르게 구성
- [x] 제한 시간이 0이 되어도 실패하지 않고 거품 공격으로 제거할 수 없는 `무적 귀신 고래`가 출현해 플레이어를 공중 추격하도록 변경
- [x] 귀신 고래 출현 시 붉은 위험 화면 효과, 경고 효과음, 빠르고 불협화음이 섞인 긴장 BGM으로 자동 전환
- [x] 모든 스테이지 제한 시간을 100초로 통일

귀신 고래가 출현한 뒤에도 일반 적을 모두 제거하고 간식을 획득하거나 EXIT를 완성하면 스테이지를 클리어할 수 있다. 다음 스테이지가 시작되면 음악과 화면 효과는 일반 상태로 돌아간다.


## 추가 업데이트 사항 5

## 추가 업데이트 사항 5 반영 결과

- [x] 무적 귀신 고래를 커다란 눈구멍·코뼈·이빨·뼈 꼬리가 보이는 해골 고래 외형으로 변경
- [x] 60초를 기준으로 스테이지 제한 시간을 70초 → 65초 → 60초 → 55초 → 50초로 조정
- [x] 12초 동안 이동 속도를 50% 높이고 점프력을 강화하는 `스피드 신발` 아이템 추가
- [x] 15초 안에 받는 공격 한 번을 생명 감소 없이 막는 `보호 방패` 아이템 추가
- [x] 물·불·신발·방패 아이템을 스테이지에 분산 배치해 후반 스테이지일수록 조합 선택이 많아지도록 구성
- [x] EXIT 알파벳을 매 처치마다 확정 드롭하던 방식에서 적 처치당 22% 확률로 변경

EXIT 글자는 `E → X → I → T` 순서로 등장하지만, 이제 한 스테이지에서 네 글자가 모두 나오는 경우는 드물다. 글자가 등장하지 않아도 모든 적과 간식을 정리하는 일반 클리어에는 영향을 주지 않는다.

## 추가 업데이트 사항 6 반영 결과

- [x] 6~10스테이지에 서로 다른 발판 색, 배경 장식, 기류와 48·47·45·43·40초 제한 시간 적용
